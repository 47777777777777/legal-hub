💡 如何複製中正 AutoRPA 的 sessionid（必看指引）
中正校園代理的通行證為 sessionid（瀏覽器 HttpOnly 安全機制會將其隱藏，無法從主控台讀取）。請選以下任一種方式複製：
【方式一：最推薦】從 Application 複製 sessionid
1. 登入法源後在分頁按鍵盤 F12（或右鍵點「檢查」）。
2. 上方切換至 Application（應用程式）分頁（若沒看到可點 >> 展開）。
3. 左側清單展開 Storage → Cookies，點擊 autorpa.lib.ccu.edu.tw。
4. 在表格中找到名稱為 sessionid 的那一欄，雙擊複製它的值（約 32 碼英數字），貼在下方輸入框即可！
【方式二】從 Network 複製完整請求標頭
1. 在登入後的法源分頁按 F12 切換至 Network（網路），按 F5 重新整理。
2. 點選清單中最上方第一筆請求，在右邊 Request Headers 找到 Cookie:，複製整行並貼上（系統會自動萃取）。
