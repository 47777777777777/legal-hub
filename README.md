# Legal Hub - 專業法規閱讀與條文深度研析系統

符合人體工學的現代法律檢索與深度研析平台，收錄全資料庫 11,804 部法規（含 1,351 部立法院制定法律與 10,453 部行政院各部會法規命令）、共 222,116 條完整條文（其中 47,377 條立法院制定法律條文 100% 逐字與全國法規資料庫 ChLaw.json 核對一致）。

## 核心特色
- **零嵌套滾動**：電腦與手機皆為單一自然流暢滾動，告別雙重滾輪與被遮擋困擾。
- **條文深度研析面板**：
  - 💡 **重點摘要**：條文核心主旨提煉
  - 📖 **白話與實務解讀**：以情境化生活例子拆解構成要件與法律效果
  - ⚖️ **法律定性**：拉丁法諺、規範客體、主觀責任、法定刑度、訴訟特性
  - 🔍 **思考脈絡與邏輯判斷流程圖**：SVG 向量決策樹，自適應螢幕
  - ❓ **大家也在問**：Q1~Q12 爭點與實務問答手風琴
  - 📊 **容易搞混**：刑法、行政法、民法跨領域概念比較矩陣
  - 📜 **相關函釋**：司法院與主管機關函釋令，100% 免費無上限快速跳轉
  - 🔗 **內容連結**：關聯法條、憲法法庭判決、最高法院大法庭裁定、司法院裁判書、月旦知識庫與法源 AutoRPA 捷徑
  - 📜 **立法理由**：制定意旨、立法院審議公報與新舊條文對照 Diff
- **多法規研究分頁**：支援同時開啟多部法規並行研讀（全功能解鎖，無 VIP 限制）。
- **個人書籤與收藏庫**：本地安全儲存，免登入帳號隨時標記重點。
- **手機專用 0-9 條號撥號盤**：解決手機軟體鍵盤遮擋畫面問題，直達特定條文。

## Hugging Face Spaces 部署說明 (50GB 免費空間)
1. 在 [Hugging Face](https://huggingface.co/) 註冊或登入帳號。
2. 點擊右上角頭像 ➔ **New Space**。
3. 設定 Space 名稱（例如 `legal-hub`），License 選擇 `MIT`。
4. **Space SDK 選擇 Docker** ➔ **Blank**。
5. 點擊 **Create Space**。
6. 在該 Space 的 Repository 中，將本 GitHub 倉庫連接同步，或透過 Git 將此倉庫 push 至 Hugging Face 提供的遠端地址。
7. Hugging Face 將自動識別 `Dockerfile` 並構建運行，幾分鐘內即可獲得永久專屬 HTTPS 網址（例如 `https://<your-username>-legal-hub.hf.space`），手機出門隨時連線！
